# Image Credits

This project includes Bhutanese hospital placeholder SVG files under `frontend/public/images/hospitals`. The app loads these as local placeholders until real licensed healthcare images are added.

To replace placeholders with licensed files, add the following files in the same folder and update the hospital `image` property in the seed data:

- jdwnrh-thimphu.svg
- phuentsholing-general-hospital.svg
- eastern-regional-referral-hospital.svg
- central-regional-referral-hospital.svg
- paro-hospital.svg
- trashigang-hospital.svg
- punakha-hospital.svg

Licensing note: these placeholder files are generated local assets and can be replaced with Wikimedia Commons or other appropriately licensed images.
